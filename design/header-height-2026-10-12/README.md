# Header 高度对比

用户已确定缩小 **25%**，作为网站默认方案。原高度及 10%、20%、30% 对照保留供回看。对照页使用发布前的实际网站截图，各档的 Logo、字体、图标尺寸与横向间距一致；按照用户确认的标准，将左上角方块与文字作为一个整体居中。组合从方块顶部到文字行框底部共 34px，在 48px 导航点击区域内上下各留 7px；文字相对方块的位置与展开后的标题位置保持一致。

预览地址：[对照页](http://localhost:3011/comparison.html)。可切换桌面和手机截图，每档都有真实网站整页链接。

| 视口       | 原高 | −10%   | −20%   | −25%（已选定） | −30%   |
| ---------- | ---- | ------ | ------ | -------------- | ------ |
| ≥1280px    | 96px | 86.4px | 76.8px | 72px           | 67.2px |
| 768–1279px | 88px | 79.2px | 70.4px | 66px           | 61.6px |
| <768px     | 80px | 72px   | 64px   | 60px           | 56px   |

选定方案：桌面 96 → 72px，平板 88 → 66px，手机 80 → 60px。手机搜索及菜单按钮仍为 48px 高。

## 实现与运行

- `components/Header.module.css` 通过 `--header-height-scale` 缩放各断点的最小高度，保留 flex 居中。
- `components/Header.tsx` 只在开发模式读取 `?headerReduction=0`、`10`、`20`、`25`、`30`；未传入或其他值使用已选定的 25%，生产构建忽略该参数并使用 25%。
- 启动网站：Yarn 3.6.1 执行 `yarn dev`，默认端口 3000。
- 启动对照页：在仓库根目录执行 `python3 -m http.server 3011 --bind 127.0.0.1 --directory design/header-height-2026-10-12`。
- 截图为 1440px 桌面和 390px 手机的实际渲染，对照页按容器宽度等比缩放，标注为真实 CSS 尺寸。

## 检查

- 已选定的 25% 默认方案在 320、390、768、1024、1280、1440px 下检查通过：高度分别为 60、60、66、66、72、72px，组合与图标中心偏差为 0，无横向溢出，见 `selected-measurements.json`。
- 25% 默认方案的键盘下拉导航检查通过；生产导出 HTML 确认默认比例为 `0.75`。

- `yarn lint` 通过，`git diff --check` 通过。
- 相同源码的隔离副本运行生产 `yarn build` 通过，76 个页面生成完成，避免构建覆盖正在预览的开发缓存。
- 此前四档在 1440px、390px 逐一测量；最紧凑 30% 额外检查 320、768、1024、1280px。无水平溢出，方块与文字组合、Logo 和搜索图标相对 Header 的中心偏差小于 0.01px，详见 `measurements.json`。
- 30% 桌面档通过方向键打开下拉菜单、聚焦首个子链接、Escape 关闭；下拉内容未被 Header 裁切。
- 30% 手机档菜单打开/关闭、搜索面板打开通过。
- 对照页桌面/手机按钮、尺寸标注和截图切换通过。
