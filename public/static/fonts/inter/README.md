# Inter

Variable roman and italic web fonts by Rasmus Andersson, downloaded from the
[official Inter repository](https://github.com/rsms/inter/tree/master/docs/font-files).
The original SIL Open Font License is included in `OFL.txt`.

On 2026-10-17, Avenir Next was selected after comparison on the Research page.
Inter remains a retained alternative for a future typography change. These files
are not imported, preloaded, or applied by the current site.

Keep both font files and `OFL.txt` together. See the
[typography decision](../../../../design/typography.md) for the active font setup
and how to use Inter in the future.
